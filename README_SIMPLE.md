# 群通知提醒助手 - 简单使用指南

## 给女朋友的版本 😊

### 第一步：下载
把 `group-reminder-app` 整个文件夹复制到她的电脑上。

### 第二步：启动
**双击 `start_enhanced.bat`**
- 第一次运行会自动安装依赖（等几分钟）
- 之后每次双击就能用
- 会自动打开浏览器，弹出二维码

### 第三步：手机扫码用
- 用微信或手机浏览器**扫弹出的二维码**
- 或者手动输入屏幕上显示的地址
- 点击浏览器菜单 → "添加到主屏幕"，就像普通 App 一样

### 第四步：创建提醒
有两种方式：

**方式A - AI 智能识别（推荐）**
1. 点击顶部 **🤖 按钮**
2. 粘贴收到的微信消息，比如：
   - `明天下午3点交作业`
   - `周五晚上聚餐`
   - `下周一记得带身份证`
3. 点"识别" → AI 自动填好时间和分类
4. 点"确认创建" → 保存

**方式B - 手动创建**
1. 点左下角"新建提醒"
2. 自己填标题、内容、时间
3. 选分类（群通知/任务/作业）
4. 保存

### 提醒频率设置
创建提醒时可以选择：
- **一次性** - 只提醒一次
- **每天** - 每天同一时间提醒
- **每周** - 每周同一时间提醒
- **自定义** - 用 cron 表达式设置复杂规则（如"工作日每天9点"）

### 到了时间会怎么提醒？
- 💻 电脑弹窗（右下角弹出）
- 📱 手机推送（如果页面在后台）
- 🔊 提示音（需要开声音）

### 分享给女朋友的方法

**方法1 - 同一WiFi（最简单）**
- 确保两台电脑/手机在同一WiFi下
- 都用 `start_enhanced.bat` 启动
- 手机扫二维码即可

**方法2 - 任何地方都能用**
- 先运行 `start_enhanced.bat` 启动服务
- 再双击 `setup_cloudflared.bat`
- 会生成一个 `https://xxx.trycloudflare.com` 的链接
- 把这个链接发给女朋友，她在任何地方都能打开

### 常见问题

**Q：电脑关机后还能收到提醒吗？**  
A：不能，服务运行在电脑上。建议保持电脑开机，或者用手机定闹钟做备份。

**Q：数据会丢吗？**  
A：不会。所有提醒都保存在 `backend/reminders.db` 文件中，只要不删这个文件，数据就一直在。

**Q：怎么停止服务？**  
A：关掉 `start_enhanced.bat` 的黑窗口即可。
